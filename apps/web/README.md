# @vjt/web

The web app: a Vite + React single-page app with React Router, Tailwind CSS 4 and shadcn/ui. It shares logic with the phone app through `@vjt/core`, `@vjt/api-client` and `@vjt/design` (ADR-0010). Its screens follow [docs/design/ui-plan.md](../../docs/design/ui-plan.md).

## Develop

The shared packages are consumed from their built output, so build them once (and after changing them):

```sh
pnpm turbo run build --filter=@vjt/web...   # or: pnpm --filter @vjt/core run build
pnpm --filter @vjt/web dev
```

`vite` serves on http://localhost:5173 and proxies the API paths (`/auth`, `/me`, `/stories`, ...) to the Go server, so login is same-origin as in production. The proxy target defaults to `http://localhost:8080`. Point it elsewhere with `VJT_API_ORIGIN`:

```sh
VJT_API_ORIGIN=http://docker-dev.internal:8080 pnpm --filter @vjt/web dev
```

A page load (a request with `Accept: text/html`) is never proxied, so reloading `/stories/12` gets the app, as it does from the Go server.

## Check

```sh
pnpm --filter @vjt/web typecheck
pnpm --filter @vjt/web lint
pnpm --filter @vjt/web test
pnpm --filter @vjt/web build    # tsc --noEmit && vite build, output in dist/
```

## Conventions

- Colours, type sizes and fonts come from `@vjt/design` (through the Tailwind classes or `var(--…)`). The lint rules `vjt/no-hardcoded-color` and `vjt/no-inline-font-size` reject hex and rgb literals and numeric font sizes.
- Theme (Light / Dark / System) and the Story text size are saved per device in localStorage. The no-flash script in `src/theme/bootstrap.ts` applies the theme before the first paint.
- Fonts: `public/fonts/` holds the unicode-range slices generated by `scripts/subset-fonts.mjs`. `src/index.css` declares them.
- Route guard and `next` handling: `src/routes/RequireSession.tsx` and `src/routes/nextPath.ts`. Only same-origin paths are accepted after login.
