# Pitch accent data comes from Kanjium (CC BY-SA 4.0)

The Reading Panel shows a pitch accent graph for each word. JMdict has no pitch data, and MaruMori's is off limits (see ADR-0002), so we use Kanjium's accent list. Where a word has several patterns we show the most common one, and words not in the list show no graph. The list is licensed CC BY-SA 4.0. Running the app ourselves, self-hosted, is fine. If we ever distribute the pitch data itself, for example as a downloadable dataset or bundled in a public app, the share-alike terms apply and need checking first.
