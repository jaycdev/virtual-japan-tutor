# Grammar Catalogue is seeded from the JLPT grammar spreadsheet, which we have full rights to use

The Grammar Catalogue is imported from the "JLPT Grammar" spreadsheet: 831 Grammar Points across N5–N1, each with a JLPT Level, a Japanese pattern, romaji and a short English meaning. The file credits jlptsensei.com, but we have full rights to use this data, including for future multi-user or public releases, so it does not need to be rewritten. Explanations and example sentences aren't in the spreadsheet. They are generated with AI and stored alongside the imported data.
